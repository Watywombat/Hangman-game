# Hangman Game 🎲

This is my first Python project, created during my early days in programming at school. It's a simple, text-based **Hangman game** that I built in just a few hours as part of an introductory exercise. 🐍

---

## Features

- **Classic Gameplay:** Guess the word one letter at a time before running out of attempts.
- **Random Word Selection:** The game chooses a random word from a predefined list.
- **Dynamic Feedback:** Displays the correctly guessed letters and underscores for remaining letters.
- **Simple UI:** A straightforward terminal-based interface.
- **Retry Option:** Restart the game after a win or loss.

---

## Technologies Used

- **Python 3:** The entire game is coded in Python, focusing on basic concepts like:
  - Loops and conditionals.
  - String manipulation.
  - Randomization.
  - Lists and dictionaries.
